**The model choices the slices take** (the opus builders may revise them, recording why in a line of D173's note):

The session's new commit then lapses everything after the work, so the review and the landing run again.

- **Routes not taken are derived each pass, never stored.** NodeRuntime.End (:1142) already ends a run once nothing can move, so a run whose untaken routes leave nothing to start has ended.
- **A step's role is an opaque option `role`**, only on the agent steps `claimed` and `opinion`. It is resolved and kept at the run's bind, so the start plan reads a fixed role. ROLESTEP1b decides whether an older build may ignore it.
