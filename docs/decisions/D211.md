## D211 — The root README is the landing page the CLI package ships: it opens on the product, links only absolutely, carries the agent rules llms.txt and context7.json repeat, and a check reads it as its registry would; the reference is docs/guide (2026-10-24)

**Decision (GITHUBDOCS1, 2026-10-24).** The CLI's pack stages the root README (`tools/stage-package.mjs`), so npm shows it as
the package's page and GitHub as the repository's. It is written for both:

1. **It opens on what Daoris is**: the pitch, a quickstart, what is in the box, the package table, the status and the rules a
   coding agent gets wrong, then where to learn more and how to develop Daoris. The long reference (the commands, the manifest,
   the layers, the seams, the parts beyond the CLI) moved verbatim to `docs/guide/README.md`, which `docs.tracked` names as the
   CLI's description and the command-table test reads. The guide writes a pinned version as `<version>`: `release-prep` stamps
   the README's install lines alone. The guide also holds the text for GitHub's *About* box and social preview, which are the
   owner's settings on GitHub; nothing here sets them.
2. **Every link in it is absolute** (`https://github.com/JiarongGu/Daoris/blob/main/…`, a raw link for an image), because npm
   renders it away from the repository. It holds no raw HTML, which npm's sanitizer drops and another registry shows as text,
   and no comment inside a code block. The logo is `docs/assets/daoris-logo.svg`, the seal at a declared 36 px, a markdown image
   in the title. An in-page `#anchor` and a comment outside a fence are allowed: GitHub and npm follow the one and hide the
   other, and the agent-rules markers are such comments.
3. **The agent rules are one text in three files.** README's `agent-rules` block is canonical; `llms.txt` repeats it and
   `context7.json` carries it as `rules`, since an agent trusts whichever file it was handed. Each rule is one line and at most
   255 characters, because Context7 skips a longer one with only a line in its own log. Both agent files index the adopter
   documents, the doctrine and the examples, and leave the records out.
4. **`tools/doc-links.mjs`, in `verify`, holds all of it**: every link in the documents resolves, relative or absolute into this
   repository, against git's own file list so a wrong letter case fails as GitHub would on a case-blind disk, with its `#anchor`
   by GitHub's slug rule; the three copies agree; the shipped README reads right on its registry. History by definition (the
   archive, the decisions, the task archive, the fix log, the changelogs) and fixtures are not read. The universal `links` gate is
   unchanged: it serves every adopting repository, and this repository's URL and README are its own.
5. **The package carries its icon, its release notes and its keywords** as npm allows: npm has no icon or release-notes field,
   so the icon is the README's logo (with `docs/assets/daoris-icon.png`, rendered by `tools/make-icon.py`, for any page that takes
   one), the changelog ships inside the package, and a GitHub release links it at its tag; `package.json` names its keywords,
   repository, homepage and issues.

**Proof.** `tool-test/packed-readme.test.ts` packs the CLI whole from a copy under `_fixtures/` and reads the README out of the
tarball as npm renders it; seen failing on a relative link planted in the README. `tools/doc-links.test.mjs` plants each fault;
on the real tree, a misspelled guide link and an unequal `context7.json` rule failed `doc-links` before both were restored.
`test/readme-quickstart.test.ts` runs the README's own quickstart lines in a fresh repository.

**Rejected.** *Relative links, left to the registry to resolve:* what npm makes of one depends on its `repository` field, and
other registries empty it; an absolute link is right everywhere. *The logo as HTML with a width:* npm drops the
attribute set and a registry that shows HTML shows it as text; a markdown image cannot be sized, so the size lives in the SVG.
*The checks in the devkit's universal `links` gate:* they name this repository's URL and README, and the devkit's gates hold for
every adopter. *The guide as `docs/guide.md`:* Context7 indexes folders, not files, and `docs/` holds the records and contracts
the agent files leave out, so the guide has a folder of its own. Shenora's D98 and Lyntai's D197 made the same moves on
2026-10-22 and 23; their commits were read, not copied.
