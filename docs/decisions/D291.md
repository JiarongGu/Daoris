## D291 — The install's `daoris` is a program, `daoris.exe`, in place of a batch file and a shell script: its arguments reach the desktop's program whole (2026-11-13)

**Decision (SAYLINES1, 2026-11-13, under D124 §1.2 and ONEWAY1ai).** A batch file's `%*` ends at the first line break, so
`daoris session say <id> "<several lines>"` delivered the first line and said nothing of the rest. A go for a production release reached
Ask Daoris without its steps and without the limit "do not release it to everyone", and the agent following the plan it had released a
test version to a customer's users for about a minute. The command is now one program in `app/bin/`:

1. **`daoris.exe`** (`Daoris.Desktop.Command`, framework-dependent, published beside the git doors and laid out whole after them) starts
   `app/daoris-driver/daoris-driver.exe`, found from its own folder, with each argument as it was given (`ProcessStartInfo.ArgumentList`
   quotes each one so a line break, a quote or an empty word reads back as it was) and ends with the program's exit code. Nothing is
   redirected, so the program's streams are the terminal's. Command Prompt and PowerShell find it by `PATHEXT` (`.EXE` before `.CMD`),
   and Git Bash finds it by its name.
2. **It replaces both launchers.** `daoris` (the shell script) and `daoris.cmd` are no longer written, and a republish removes them with
   the folder (D228: one way). `CLI_LAUNCHERS` is `['daoris.exe']`; `layCli` leaves `app/bin/` empty and `layCommand` lays the program.
3. **The one linked file** is `Platform/CommandLauncher.cs`; its start, its words and its path to the program are held by
   `CommandLauncherProcessTests`, and `desktop-publish.test.ts` holds its name and path to the publish's.

**Rejected.**

- *Words read from standard input when the words argument is `-`.* It makes the multi-line form possible and leaves the silent
  truncation in place for every caller that does not know to use it, which is the failure that happened. A command that cannot lose the
  words needs no convention from its callers.
- *A batch file that detects a line break.* A batch file cannot see what follows the first line of `%*`.
- *Copying `daoris-driver.exe` to `app/bin/daoris.exe`.* An apphost names its library beside itself, so the copy finds none. Moving the
  driver's folder into `app/bin/` would rename `app/daoris-driver/`, which D124 keeps for good and the rehearsals and tests name.

**Costs.** A second .NET start before the program's own; a third small program in `app/bin/`, built and laid
out by every publish; the shell-word test builds the command with `dotnet publish` and runs on Windows only, where the install is.
