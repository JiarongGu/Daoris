## D337 — A failure stops only its region (2026-11-20)

**Decision (UISH17, the window redesign `docs/2026-11-19-window-design.md` §15.9; amending D217 and desktop-app rule 21).** The
page's error boundary mounts per region (the main area, the side bar, each overlay), each drawing `RegionState`'s *stopped* form:
what failed, *Try again*, *Copy the details*. The rail, the waits pill, the title strip and the other regions stay pressable.
`page.error` names the region and the address beside D217's view and first frames. The whole-page error screen remains for a
failure of the frame itself.

**Why.** One broken page today takes the whole window with it, waits included; the owner must be able to answer a wait while a
screen they were not reading is broken.

**Rejected.**

- *One boundary for the page* (today): a failure anywhere hides the waits.
- *A boundary per component*: notices scattered through a page, each without the context of what it was part of.
