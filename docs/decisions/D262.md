## D262 — A session is handed the person's own tool home through the harness's session-only doors, family by family, each the person's to switch off (2026-11-11)

**Decision.** A session runs in its account's home (D175, D197), so the skills, subagents, commands, servers, plugins and Chrome switch
the person's own run of Claude Code loads from its tool home never reached it (AGENTFREE1's census row 23, against D253 point 7). The
spawn now reads the person's tool home where their own run would (`CLAUDE_CONFIG_DIR`, else `.claude` in the profile, its global file
beside it) and hands what it holds through the doors a harness keeps for one session: the skills, subagents and commands copied into one
harness plugin, `own`, under the session's spawn folder; the user-scope servers in that plugin's `.mcp.json`; each enabled user-scope
plugin at its install folder; and the Chrome switch as `--chrome` on the native door. Each family is a default of the person's rules
(`own-skills`, `own-servers`, `own-plugins`, `own-chrome`), on until switched off. The floor keeps out a server named as Daoris's
connector or carrying a Daoris variable, and a pass held to Daoris's connector alone is handed no server. Nothing is handed to a session
in the person's own home or under a scratch home.

*Rejected:*
- **Running the session in the person's own home.** The account walk chooses the home (D197); the person's own sign-in stays outside
  the set (agents rule 28).
- **Linking or copying the pieces into the account's home.** Daoris writes no account home (D230); a link's removal could reach the
  person's own files, and every later session of that account would carry them whether the person's switch says so or not.
- **`--add-dir` of the person's tool home.** It loads its skills but grants its files too, the credentials beside them included.
- **Merging the person's `settings.json` into Daoris's rules file.** The one command-line tier would raise their user settings over the
  repository's project settings, which no by-hand run does; settings and the memory file stay open.
- **A switch on the agent's page instead of a rule default.** The person's rules are where Daoris narrows (D253 point 7), and a default
  is listed, switched and proposed there already.

**Amends** D230 (a Claude session keeps its account's own and is handed the person's own tool home besides).
