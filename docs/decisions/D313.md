## D313 — A scoped semantic census binds the trees a change reaches, found from a reference map, not a kept compilation (2026-11-17)

**Decision (CENSUSDIFF1).** At a merge (`CENSUS_SCOPE`), a semantic census (the structure classes; the declarations' literals,
boundary and keepers) binds only the trees of the merge's files and of the files that spell a type one of them declares (its name, an
attribute's shorthand or a global alias), wherever they compile, and a shipping project none of whose sources is reached is not
compiled. Which file spells what is the reference map (`CensusReach`, `ReferenceMap`): each source's declared types, spelled names and
global aliases, read from the syntax alone and kept under `_fixtures/census-reach/` by the hash of the map's format and the source's
text. The keepers' flow crosses files only within a project, so it runs whole in each project reached. A list's row is judged only
where its file was read. With no scope every census binds the whole tree as before; a semantic census that must stay whole says why
in `CensusMarks.SemanticWhole` (none today).

**Why.** Binding, not parsing, is the cost: alone, the driver's whole walk binds every name in about 29 s and its error check takes
about 22 s more, where its compile (the parse) is about 3 s and the reach of a merge's files a fraction of a second. A file's verdict
under these rules moves only when its own text or a type it names changes.

**Rejected:** keeping a compilation between runs (Roslyn writes none to disk, and a new process binds again whatever it parsed);
keeping each census's verdict by the whole tree's hash (every change misses); a reach by the members a change declares as well as its
types (common member names reach most of the tree); judging the merge's own files alone (a breach in a file that names a changed type
would pass).

**Note, 2026-11-17 (the text censuses).** The per-file text censuses follow the same rule through the shared scan: a census whose rule
judges a file on its own text, or lists files both ways, judges the scope's files and their listed members; ten driver classes are
diff-able this way. A text census stays whole when its rule is a count, a ratchet, a uniqueness ("exactly this file") or a relation
between files (holders and writers of a lock, a table of reads held both ways with a floor), when it is a table of behaviour (the
goldens' text, the provider table), or when its cost is under a second and its walk shared (the modules' text censuses, 8 to 11 s in
all). Each remaining whole class is a class to convert when its time shows in the gate.
