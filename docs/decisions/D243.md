## D243 — A conversation's native retry replays its unacknowledged words from the run's `DoorInput`, never a stream the run re-hands (2026-11-06)

**Decision (AGENTPROVIDER1m-ii).** A native conversation that goes on and whose harness ends on a failed exit before it names its
conversation is tried once more inside its run, as a driven native resume is (D210 point 8's policy, `TransientRetries`, unchanged).

1. **The words are the run's.** A conversation's words reach its process through the run's `DoorInput`, one queue per run with each
   word's id: a word is attempted before its line is written, written as the write returns, and acknowledged once the harness names
   the conversation it went to. Nothing above the run writes to a process's stdin.
2. **The retry replays what was not acknowledged.** The restarted process is handed, in order, every word written to the process that
   ended before naming its conversation: that process never opened it, so it took none of them. A word acknowledged is never written
   again, and a word said during the restart waits in the queue behind them.
3. **One retry, the run's own.** The run restarts the same resume once, under the same record, which stays working; a second such end
   concludes `exited`. The chat's runner starts no second run for it.

**Rejected.**
- **A stable input stream the run re-hands to the restarted process.** A stream holds no word's identity: the bytes written into the
  ended process's pipe are gone with it, so the run could replay either nothing, losing the go-on's words, or everything it ever wrote,
  repeating a word the conversation already took. Telling which words to replay needs the queue of point 1 anyway.
- **The retry kept in the chat's runner, a second run of its own.** It holds the conversation's tabs, turns and files twice for one
  resume, and its words reach the second run only because the runner composes the go-on again; the driven native retry is already the
  run's (`IResumeState`), and two ways to retry one resume is a second way to do one job (D228).
