## D287 — A typed tool module reaches an untyped script through a declaration beside the script (2026-11-13)

**Decision (MERGETS1, 2026-11-13).** The merge tool moves, module by module, from `tools/merge-branch.mjs` into strict TypeScript
under `tools/merge/`, which Node runs by type stripping and `npm run typecheck:tools` checks. Strict `tsc` refuses an import of an
untyped `.mjs`, and the modules about to move import the repository's scripts (`fsx.mjs` first: the one way a tool starts git and
writes a file; then `run-lock.mjs`, `process-reach.mjs`, `test-map.mjs` and others). One way is chosen for every such import.

1. **A `.d.mts` beside the script.** A typed module imports `tools/<name>.mjs` as it is, and `tools/<name>.d.mts` declares the
   script's exports, every one and nothing else. The repository already reaches its untyped scripts this way (`listen-port.d.mts`,
   `stand-ins.d.mts`, the page's `scripts/*.d.mts`, the CLI's `bin/node-floor.d.mts`). `tools/merge/declarations.test.ts` holds
   each declaration in `tools/` to the names its script exports, so a script that gains, loses or renames an export fails the unit
   project until its declaration says the same. The first is `fsx.d.mts`, and `flow-deps.ts` starts git through `spawnGit` with it.
2. **A seam stays the way to fake an effect, not the way to reach a helper.** `flowSeams` hands `flow.ts` the runner's effects so a
   test can stand them in; a pure helper or a leaf is imported, never threaded through a seam object.

**Rejected.** *Seams for every script* (the runner hands each typed module the helpers it needs, as `flowSeams` does): every call to a
pure helper becomes a field of a dependency object the runner must wire and every test must fill, and a leaf such as starting git
gains no fake worth having. *`allowJs` with `checkJs: false`*: the typed program would read each imported script and everything
it imports (the runner's 7,000 lines among them), and since an unchecked script's parameters are untyped, a strict module's call
into it is checked against nothing: the types the move is for would stop at the first import.
