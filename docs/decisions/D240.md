## D240 — The backlog completed whole, git managed by design, and the proofs that spend kept small (2026-11-05)

**Decision (the owner's answers to the backlog plan, `docs/2026-11-05-backlog-plan.md` §2).** The backlog is completed at a fast pace
in big chunks, then reviewed whole: the code and the documents.

1. **Nothing related stays parked.** AGENTPROVIDER1 is built whole (rows d to u, with ONEWAY1 h, g and ah), and every parked row
   related to a built row comes back with it. D233's freeze ends for those rows.
2. **HOMELAYOUT5 and ONEWAY1w are built.** Each harness's account home is moved, measured on the install with the owner's sign-in per
   harness.
3. **The git transport judge is kept (GITAUTH1g).** A system where many agents work cannot wait on the person for every grant, so the
   judge decides dangerous transports (tags, mirrors, prunes) itself, and a grant is bound to its ref.
4. **Git is managed by design (GITDESIGN1).** Installing tools to measure the doors is not the answer. Daoris either keeps git out of
   its core, with git's processes in a plugin, or relies on git and proves its built-in path end to end. GITDESIGN1 writes that design
   first, and GITAUTH1b and WORKSETUP1 follow it.
5. **A pull request is not a default.** Daoris opens none by itself. Where a place needs one, its workflow composes it from git steps,
   configured per place, and auth is applied correctly first. WORKSETUP1 is reworked on that basis; the current setup is not applied.
6. **This repository's integration moves to Daoris's own integrate workflow (INTEGRATE1k).** The steward sets it up from the terminal
   once the install is staged.
7. **Spend on proofs is allowed, kept small.** Each proof that needs an account's model runs once, at the least that proves it, and its
   spend is reported.
8. **AGENTLYNTAI1 builds against Lyntai's local library.** No release is published for it; Lyntai's own process makes its published
   versions work.
9. **Codex's owed reads become Opus reads while Codex's spend cap holds** (the steward's call); Codex reads them again if the cap lifts.

**Rejected.**
- Parking AGENTPROVIDER1's host rows under D233: the owner wants the whole system.
- Cutting the transport judge and having the person press for each tag push: unworkable with many agents.
- Installing sshd, `gh`, `az` and git-lfs to measure the doors before git's place in Daoris is designed.
- A pull request as a default capability of every place.
