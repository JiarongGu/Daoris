## D353 — Whether a declaration's commands wait for the owner is the repository's access mode: restricted waits, full access takes them (2026-11-20)

**Decision (GATEACCEPT2).** One reader (`DeclarationMode`) answers whether a repository's `daoris.gates.json` waits for the owner,
from its access mode: full where the repository's permission prompts resolve `unrestricted` (full access gives that, at the
repository, workspace or machine level, as its sessions' own setup resolves), restricted otherwise. Under restricted access D350
stands as written. Under full access nothing waits: a work's check runs the declaration its own commit carries, a command change of
its own included, and its result names that blob; the line's declaration is accepted as it lands and said in one line ending
`(full access: taken without asking)`, so *What needs you* holds no acceptance row; and a check held `changed` is run again by itself
once its repository takes full access, under the same acceptance as it held. The check (`CheckDeclaration`), the line's acceptance
(`IntegrationOwed.ByMode`, `DeclarationAcceptance.AcceptByModeAsync`), the held checks' rerun (`ChangedChecks`) and the window (Setup
says the mode; a restricted row begins *Restricted: waits for you*) ask that one reader.

**Why.** A full-access agent runs any command in its own session without asking, so holding Daoris's check of that agent's commands
for the owner adds no safety, only a stall: on 2026-11-20, with `machineAccess = "full"` and `access.Daoris.permissions =
"unrestricted"`, Daoris's checks held `changed` for six hours. The owner's choice of access is the grant; a second acceptance of the
same commands asks for it twice, and Daoris is not made to block progress.

**Rejected.**

- *Every pause open (`ResolvedAccess.Full`), which the line's acceptance read before*: a repository whose agents run commands with no
  prompt while its routing or go-aheads still wait for the person would hold checks of commands its agents run anyway. The grant in
  question is running commands, which is the permission prompts.
- *Ask Daoris's restricted or full mode*: that is the console's own conversation, one machine choice for one agent, not the
  repository's sessions.
- *A switch of its own for declarations*: a second setting for the same grant, which drifts from the first.
