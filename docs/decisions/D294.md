## D294 — A Process class's real waits, starts and git are its subject; the census judges an over-budget test by its class alone (2026-11-15)

**Decision (LAYERSRED2).** Two rules of the layers census (area `code-structure-and-process.md`, rule 21):

1. **A source whose type carries `[Trait(Category.Name, Category.Process)]` is exempt from the census's real-wait, process-start and
   git findings.** A real-process test's wait on its process or watcher, the process it starts and the git it runs are what it
   proves. Its reads of "now" (`DateTime.UtcNow`, `TimeProvider.System`) still count: they take a `TimeProvider` or `MovedClock`
   like any other code. A helper that exists only to serve such tests carries the trait too.
2. **A unit test over its second is a finding only if its class, run again alone, is still over.** Records written while merges
   and builders load the machine are not judged; the census runs the over-budget classes alone through the time ratchet's own
   mechanism (`measureAlone`, `unitsOf`) and reads the newer records, as the ratchet judges time.

**Rejected:** an allowance per new Process file in `tools/layers-census.json`. The list only falls; a list that grows with every
Process class is a list nobody reads, and each such file would hold its allowance for a wait that is its subject.
