# Decisions: history, and where each one's rule lives now

The decisions are history. The current truth is in `docs/areas/`, one document per area, each rule ending with the decisions it
replaces. Read an area first; open a decision only for the reasoning behind a rule. A new decision is written only for a choice that
rejected an alternative (`change`). This table is generated by `node tools/decision-status.mjs` from the areas' citations.

- **live:** an area document states its rule (the areas named);
- **superseded:** a later decision or the code replaced it whole;
- **history:** no area cites it; its rule, if any, is carried by a later one.
